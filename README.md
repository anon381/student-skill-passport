# Skill Passport

**Skills over grades. Proof over promises.**

Skill Passport is a platform that verifies what students can actually do.
Instead of relying only on GPA or vague CV claims, students can publish **verified skills** from real academic or project work.

Lecturers verify those skills, and employers can search for graduates based on **real, proven abilities**.

---

## Overview

Traditional academic records focus heavily on grades, which often fail to capture the full range of a student’s abilities.

Skill Passport introduces a **verified skill record system** that connects:

* **Students** – who demonstrate skills through projects
* **Lecturers** – who verify those skills
* **Employers** – who search candidates by proven capabilities

The result is a shared language of **verified, evidence-based skills**.

---

## Who Is This For?

### Students

* Turn real work into verified skills
* Build a portfolio beyond GPA
* Share a public, verifiable skill record

### Lecturers

* Verify student skills quickly
* Track learning outcomes
* Link coursework directly to demonstrated abilities

### Employers

* Search graduates by skills
* View verified proof instead of claims
* Identify candidates based on real capability

---

## How It Works

1. **Student completes a project**
2. **Lecturer verifies the demonstrated skills**
3. **Verified skills are added to the student's Skill Passport**
4. **Employers can discover and search graduates by skills**

## Getting Started

Clone the repository:

```bash
git clone https://github.com/yourusername/skill-passport.git
cd skill-passport
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
